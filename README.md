# Prashad Lelo Assets

Static production assets for **Prashad Lelo Jabalpur**.

The visual direction was developed from a Canva-generated concept and converted into lightweight SVG production assets for fast CDN delivery.

## Assets
- `assets/backgrounds/temple-pattern.svg` — subtle ornamental UI background
- `assets/branding/prashad-mark.svg` — compact brand mark

## CDN
Production should pin to a commit rather than `main`:
`https://cdn.jsdelivr.net/gh/Shreshthpatel/Sample@<commit>/assets/`
